# topic-research · 思路研究

用现有 GPT 和联网能力理清主题与思路，比较证据，交付有来源的研究报告。

这是一个轻量的研究 Skill，适用于主题、观点、关联疑问或零散想法。它复用当前模型、已有联网工具和现有账户额度，默认在聊天中交付中文报告。

## 如何使用

在已加载本 Skill 且具备联网工具的环境中，直接提出请求：

```text
使用 $topic-research，帮我研究：〔你的主题、思路或疑问〕。
```

例如：

- 使用 $topic-research，帮我研究：普通人尽早拥有“博主身份”，有哪些依据、反例和适用条件？
- 使用 $topic-research，帮我研究：“信息越多，决策越好”这个观点，现有研究有哪些不同解释？
- 使用 $topic-research，我有几个关联想法：推荐算法、信息茧房、主动搜索。帮我理清它们之间的关系，看看已有研究怎么解释。

安装与加载方式取决于你使用的 Skill 环境。本仓库提供研究工作指引，实际检索与回答由该环境的模型和联网工具完成。

## 调研方式

1. **理清问题**：保留你的关注点，提炼少量关联疑问；缺失信息明显影响研究方向时再澄清。
2. **调查现有答案**：按问题跨平台检索，阅读关键原文，优先一手资料，并合并重复转载。
3. **比较证据**：考察支持依据、反证、反例和适用条件，区分事实判断与价值取舍。
4. **交付理解**：先给简短结论，再按需要展开分歧、适用范围和未知项，重要事实就近附原文链接。

报告会区分研究发现、个人经验与推论，明确标注未读全文或无法核实的内容。研究深度随问题调整，覆盖主要解释与关键反证后收束；行动方案按你的需求提供。

## 使用条件

需要支持加载 Skill 的模型环境，以及可用的联网工具。复用现有账户额度，不额外接入收费服务。
